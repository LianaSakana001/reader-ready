# 科研论文写作

起草或修改研究论文、摘要、综述、学位论文和科研图注时使用。遵守用户提供的目标期刊和学科惯例。仅在需要时阅读对应英文指南，两种版本采用相同编辑规则。

## 文体和叙述位置

使用准确的学术表达，统一学科通用术语。程序或结果是重点时可以用被动句，期刊和作者采用第一人称复数时可以用“我们”，二者都不是统一要求。避免文学比喻、悬念铺垫、随意设问、情绪感受、个人故事和宣传式结论。

保留有意义的过渡、用于比较实验的平行描述、结构式摘要和常规章节标题。不要为了避免重复而用含义不同或模糊的近义词替换术语。以清楚为修改目标，不规定节奏、标点或句长配额。

## 有吸引力的科研论证

让读者看清研究贡献。连接研究问题、尚未解决的疑问、研究路径、关键发现，以及这些发现带来的认识变化。把这一顺序作为思考帮助，不强制套用段落模板。描述性研究、阴性结果和方法研究都可以围绕有价值的问题展开，不为凑故事编造机制。

允许调整结构时，按结果和图表在论证中的作用排序，不按分析执行顺序写流水账。明确、适度地表达有依据的进展。标题和主题句要提供信息，用已有证据和文献解释发现为何重要，避免空泛拔高，也避免平均罗列做过的一切。

有重点地组织内容，同时保留会改变主要解释的证据。结尾可以落在贡献及其意义上，无需突然新增一串通用不足。确实在回复审稿意见时，仍应直接回答对方提出的问题。

## 避免防御性写作

按证据支持的强度直接陈述发现，不在每个结果后自动追加“不能证明”“尚不能确立”“应谨慎解释”。“与……相关”这样的措辞可能已经准确限定了主张。区分整篇论文必须交代的内容和每一句话需要承载的内容。

作者提供的“没有因果证据”“不要暗示机制”等写作约束用于选择准确措辞，不自动转写成论文里的额外句子。已经准确写成相关关系且没有暗示因果时，再单独否认因果通常没有信息增量。保留具体研究发现和实质局限，同时区分这些内容与关于写法的指令。

遇到疑似限定句，判断它是否改变读者对结果的理解、交代必要条件或回应实际问题。必要信息放在需要的位置。已经由主张本身表达的边界、针对假想批评的预先辩解、为研究范围作出的道歉，可以删除重复部分或直接陈述相关范围，不再换成另一种免责声明。

实质局限放在读者需要的位置，通常是方法或讨论，避免打断每个结果。移走限定会使当前主张产生误导时，就近保留；遵守摘要和报告要求。不对限定词设禁令或数量配额。不编造较弱结果的原因，不为故事有利而重定义预设结局，不删除影响主张的不利发现。

示例：结果段报告观察性相关，研究设计和相关局限已经在文中交代。

- 原稿：`X与Y相关。必须强调，这不能证明因果关系，读者应避免过度解读。`
- 修改：`X与Y相关。`

修改后的句子没有作出因果主张。如果上下文暗示了机制，则修改这一暗示，或保留它确实需要的具体限定。

## 先核对证据，再选择措辞

起草时使用已有结果、方法和来源；修改时保留有依据的主张及其引用。区分观察、解释、假设和未来工作。不编造实验、样本特征、统计检验、参考文献、作者贡献或结果原因。

保留已有数值、分母、单位、效应量、置信区间、P值、校正方法和比较方向。不把细胞数当作独立生物学重复数。保留描述性结果和推断性结果的区别。差异不显著不能证明等效或没有作用。

保留有证据依据的限定和局限。“可能”“提示”“与……相关”“在本队列中”可以承载必要含义。只在不改变不确定性的前提下压缩重复限定。不能把相关性改成因果、探索性发现改成确证、投稿改成接收。

缺少来源或结果时，询问必要信息，或把缺口留在面向作者的工作沟通中。用户要求的工作草稿可以包含明确标出的占位符，但仍有占位符时不能称为可投稿终稿。根据已提供的投稿要求，保留必要的方法披露和AI使用说明，删除无关的聊天或制作叙述。

## 按章节功能处理

| 章节 | 编辑重点 |
| --- | --- |
| 摘要 | 交代问题、方法、有依据的主要发现和限定范围内的结论，不加入正文没有的结果。 |
| 引言 | 说明已有问题、具体缺口和研究目的，保留支持这一逻辑的文献。 |
| 方法 | 保留研究和报告要求所需的程序细节。软件版本、参数、排除标准和质控在这里可能必不可少。 |
| 结果 | 用已有定量证据交代比较和发现。解释与证据相称，期刊要求时将解释另行组织。 |
| 讨论 | 联系证据和既有研究解释发现，保留替代解释、局限和推广边界。 |
| Figure及图注 | 保留理解图所需的子图对应、定义、样本单位、组别、检验信息、比例尺和缩写，删除无关的工作名称。 |

## 示例

证据：观察性分析显示X与Y相关，尚未建立因果关系。

- 原稿：`这一突破性分析揭示了X与Y之间引人入胜的因果图景。`
- 修改：`观察性分析显示，X与Y相关。`
- 因果关系未确定这一点影响当前论述时，应保留或明确说明。不编造机制或数值估计。

已经清楚的方法描述可以原样保留：

> 样本按随机顺序处理。分析人员对分组信息保持盲态。

真实局限可以保留正式表达：

> 供体数量有限，可能影响组间差异估计的精度。

中文优先使用“本研究比较了两组的细胞组成”这类准确表达，避免通用背景和文学比喻。英文使用通行科研措辞，不为显得自然而改成“we took a look”或“the cells told a story”等口语或拟人表达。
